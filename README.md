# Smart PDF Splitter

A lightweight Node.js full-stack application that splits PDF files either by page count or into a fixed number of files, returning the processed output as a compressed `.zip` archive.

## Requirements

- Node.js (v18+)
- npm

## Setup & Running

1. **Install dependencies:**

   `npm install`

2. **Start the server:**

   `npm start`

3. **Access the application:**

   Open `http://localhost:3000` in your browser.
